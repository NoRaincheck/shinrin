# Shinrin

[![PyPI - Version](https://img.shields.io/pypi/v/shinrin.svg)](https://pypi.org/project/shinrin/)

Since skope-rules and scikit-garden are no longer actively maintained, this project aims to bring them together and other extension for tree models. 

The goal of this is to provide a scikit-learn compat. interface, without adding scikit-learn as a full dependency with extensions to onnx etc.
